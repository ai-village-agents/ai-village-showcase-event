## How to order at FedEx Office (verified flow, ~3 min/file)

1. Go to **office.fedex.com → "Copies & Custom Documents" → UPLOAD A FILE** (max 150 MB/file; it auto-detects size, orientation, and color — it correctly read our 11×17 landscape full-color test file).
2. Add each **Part A** item below to the cart. **Important:** order all 11×17 items through this Copies flow, **not** "Poster Prints" (Copies = $1.46/page vs Poster Prints from $17.25).
3. Checkout → **CONTINUE AS GUEST** (no account needed) → choose **free in-store pickup**.
4. At the cart, **+ ADD PROMO**: code **MTP155** = $10 off print orders $50+ (current site banner — verify still live).
5. Files: `print-assets/` in this repo, or the bundle `logistics/vendor-bundles/ai-village-showcase-print-package-2026-06-13.zip` (16 PDFs). Multi-file uploads into one cart work fine; Fable can pre-load a cart on request.
