# Primary Laptop Runbook v0 — Projection / Demo Driver

Purpose: one-page checklist for the person driving the projected laptop at The Fold. Source plan: `logistics/device-and-av-plan-v0.md`.

## Owner / operator

- Primary laptop owner: **TBD / likely Larissa if she prefers her laptop**.
- Operator: **TBD demo laptop driver**.
- Rule: the laptop is always supervised while in use and never left as an unattended public terminal.

## Bring

- Laptop + charger.
- USB-C to HDMI adapter minimum, plus any laptop-specific adapter.
- Optional: HDMI cable backup, clicker, mouse.
- Backup device if available: laptop preferred, tablet acceptable.

## Before guests arrive

1. Connect exact laptop to The Fold projector/screen.
2. Test audio through PA if any video/audio will play.
3. Test one microphone for MC.
4. Plug into power; disable sleep/auto-lock for the event window.
5. Turn on Do Not Disturb / Focus mode and close private tabs/apps.
6. Increase browser zoom if room is standing-heavy; projected text must be readable from the back.
7. Open only approved event tabs/assets:
   - Village live view only if needed for the optional `/tts` spoken-welcome test or confirmed clean-room Demo 2; otherwise keep chat closed/off-projector.
   - Welcome slide: `demo-assets/agent-welcome-projection-slide.html`
   - Welcome fallback PDF: `demo-assets/welcome-slides/agent-welcome-slides.pdf`
   - Village Pulse: https://ai-village-agents.github.io/village-pulse/
   - Village Arcade: https://ai-village-agents.github.io/village-arcade/
   - Project QR slide: `demo-assets/projects-qr-slide.png`
   - Demo 2 Plan-B slide: `demo-assets/demo2-collab-transcript-slide.png`
   - Run-of-show: `program/run-of-show-v1.md`
   - MC cues: `program/mc-cue-card.md`
8. Keep an offline/local copy of the key PDFs/images if possible.


## Optional `/tts` spoken-welcome upgrade

Use only if tested successfully at Thursday rehearsal and again at Saturday load-in.

- Confirm the presentation laptop audio can route cleanly to the room PA.
- Confirm the village view has "Autoplay voices" enabled.
- Each agent may post **only its welcome line** prefixed with `/tts` so the room hears the agents introduce themselves.
- Keep the projected view clean and paced; if latency, volume, or timing is awkward, drop immediately to projected text + Larissa/MC readout.
- Do **not** use `/tts` for projected Demo 2 collaboration chat; the prefix could appear onscreen and the audio could become distracting.

## If Demo 2 live Plan A is confirmed

- Project **only** the clean demo room, expected `#showcase-live` or the final human-confirmed equivalent.
- Never project `#best`, private scrollback, inboxes, file browsers with private content, or attendee data.
- The prompt-injection/operator path must be tested at the Thu Jun 11 rehearsal before using live on Sat.
- If anything looks wrong, immediately switch to the Plan-B slide/recording and let Larissa narrate the fallback.

## During the event

- 7:00–7:25: loop project gallery or welcome/QR slide silently.
- 7:25–7:32: show welcome slide / agent lines.
- 7:32–7:48: show Demo 1 / Village Pulse / project gallery as cued.
- 7:48–8:05: run Demo 2 Plan A only if confirmed and tested; otherwise Plan B.
- 8:05 onward: show project QR / Village Arcade / station support slides as useful.

## Failure switches

- Projector fails: Larissa reads MC cues; demos become spoken walkthrough + phone QR sharing.
- Wi-Fi fails: use offline PDFs/images and printed station materials; Arcade becomes QR/high-score card only if phones have data.
- Live chat risk appears: do **not** troubleshoot on projector; switch to Plan B.
- Operator overwhelmed: cut optional Demo 4 first, then keep only welcome + one reliable demo + station QR slide.
