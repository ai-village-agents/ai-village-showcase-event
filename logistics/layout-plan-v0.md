# Layout Plan v0 — The Fold

Working event: **AI Village Showcase & Human×AI Field Day**  
Date/time: **Saturday, June 13, 2026, 7–10 PM**  
Target crowd: **80 RSVPs + waitlist**, reassess if demand grows  
Venue: **The Fold**

This is a practical layout request for Larissa/The Fold, not a final floor plan. It should be adjusted once The Fold confirms which rooms/spaces are included, wall-mounting rules, A/V bundle, power locations, and setup access.

## Layout goals

1. Make the first 75 minutes feel like a coherent showcase, not a scattered mixer.
2. Let the room quickly convert from presentation/demo mode into five active Human×AI station areas.
3. Keep check-in, food/drink, and social flow from blocking demo sightlines or station circulation.
4. Avoid all floor tape and avoid wall mounting unless The Fold approves the specific surfaces.
5. Keep cords out of walkways using venue-approved routes/cable covers or battery-powered devices.

## Preferred room zones

### 1. Entry / check-in zone

Place near the main arrival path but not directly in a doorway.

Needs:
- 1 table for check-in list/Partiful QR/name tags/pens.
- 2 chairs or standing host positions.
- Small tabletop/freestanding welcome sign.
- Optional prompt-card bowl/stack for early arrivals.

Avoid:
- A check-in line that blocks stairs, entrances, restrooms, or food.

### 2. Presentation / demo zone

This is the visual center for 7:20–8:15 PM.

Needs:
- Screen/projector or main display.
- Host/MC position with laptop/clicker notes.
- Audio suitable for ~80 attendees: ideally 1 handheld mic for host + 1 backup/shared mic.
- 40–60 chairs plus standing space, depending on room feel.
- Clear aisle for late arrivals and station facilitators.

Suggested seating:
- Mixed theater/standing is fine; do not over-seat if it makes station transition slow.
- If there are couches/high-tops already in the room, use them around edges for informal seating.

### 3. Five station / booth areas

Each station needs an obvious landing point, a small work surface, and one visible instruction/sign surface.

| Station | Space need | Furniture/display | Power priority |
|---|---|---|---|
| Prompt Relay Race | small table cluster, 6–10 active participants | 1 table, cards, markers, tabletop/freestanding sign | Low |
| Event-in-a-Box | table for cards + sketching, 6–10 active participants | 1 table, cards, poster/tri-fold display | Low |
| Bug Triage Theater | table or semi-circle for role play, 4–8 active participants | 1 table, role cards/lanyards, verdict board | Low |
| Future Headline Wall | vertical display + writing space | freestanding board/easel/corkboard/tri-fold; no floor tape | Low |
| Village Arcade Booth | laptop/tablet/QR demo station, 2–6 active participants | 1 table, laptop/tablet, high-score cards, leaderboard board | High |

Placement recommendations:
- Put **Village Arcade Booth** closest to reliable power and Wi-Fi; keep it away from food/drink spill risk.
- Put **Future Headline Wall** where people can gather without blocking a passage; use freestanding boards unless walls are approved.
- Keep noisy/performative **Bug Triage Theater** slightly away from the demo audio area if possible.
- Use tabletop signs or easels so station names remain visible in a standing crowd.

### 4. Food/drink zone

Needs:
- 1–2 tables or a sideboard for self-serve non-alcoholic drinks and snacks.
- Trash/recycling/compost bins close by and visibly labeled.
- Food labels for common allergens/dietary notes.
- Napkins/plates/cups/tongs at the start of the table.

Placement recommendations:
- Near social area, not next to laptop/projector/station electronics.
- Away from the main check-in choke point.
- If drinks are in cans/bottles, consider a separate drinks end of table to reduce crowding.

### 5. Artifact / harvest display

Needs:
- 3–5 freestanding boards, easels, corkboards, or tri-folds.
- No floor tape. Wall mounting only if The Fold approves the surface and method.
- Space for MC to point to favorite artifacts during the 9:10 harvest.

Recommendation:
- Combine station display boards with the final artifact gallery where possible so outputs stay visible through open social time.

## Furniture request to The Fold

Minimum working set:
- 1 check-in table.
- 5 station tables.
- 1–2 food/drink tables.
- 40–60 chairs for presentation seating, plus existing couches/high-tops if available.
- 3–5 freestanding display surfaces if venue can provide them; otherwise agents/Larissa buy foam/tri-fold boards.

Nice-to-have:
- 1 extra table for demo laptop/AV support.
- 1 high-top or small table near entry for prompt cards.
- Easels, corkboards, rolling whiteboards, or other venue-safe display surfaces.

## Power and cable plan

Must confirm with The Fold:
- Outlet locations near presentation screen/projector.
- Outlet near Village Arcade Booth.
- Whether venue provides power strips, extension cords, and cable covers.
- Approved cable paths.

Rules:
- Do **not** tape cords to floors.
- Avoid cords across attendee walkways. If unavoidable, use venue-approved cable covers.
- Prefer battery/fully charged devices for low-power stations.
- Keep food/drink away from powered devices.

## A/V minimum

For the planned program, confirm or reserve:
- Projector/screen or main display that can show slides/chat/demo content.
- Audio output for laptop demo audio if needed.
- 1 handheld mic for MC; 2 mics preferred if live audience prompt/Q&A will happen.
- PA/speaker appropriate for ~80 attendees.
- HDMI/USB-C adapters and backup playback device.

If A/V add-ons are expensive or unavailable:
- Run a shorter, lower-tech welcome with a large display/laptop if room size allows.
- Use printed QR/signage for demos and station handoff.
- Keep recorded/screenshot fallbacks ready.

## Transition plan

- **Before doors:** stations are already staged but not visually competing with the screen.
- **7:00–7:20:** arrivals get name tags and optional prompt cards.
- **7:20–8:15:** audience oriented toward presentation/demo zone.
- **8:15–8:20:** MC points to each station by location; station facilitators stand by their station signs.
- **8:20–9:10:** chairs can remain partially in place; do not require a full room reset mid-event.
- **9:10–9:25:** MC harvests artifacts from freestanding boards/station outputs.
- **9:25–10:00:** food/social flow continues around station/artifact gallery.

## Fallback layouts

### If only one main gallery space is included

Use one end for presentation and ring the walls/edges with station tables. Keep food/check-in near the entry and Village Arcade near power.

### If a second/back gallery is included

Use the main gallery for presentation + social, and the second/back gallery for 2–3 stations that can run with less audio competition. Keep at least Prompt Relay or Future Headline visible in the main flow so station energy is obvious.

### If wall mounting is not allowed

Use foam boards, tri-folds, tabletop signs, easels, corkboards, or rolling boards. Avoid adhesive assumptions entirely.

### If setup access is short

Prioritize:
1. Check-in.
2. Demo A/V.
3. Five station tables with signs/cards.
4. Food/drink table.
5. Artifact display polish.
