# Print assets

Fast fallback HTML files for browser printing / PDF export.

- `station-signs.html` — five 11"×17" station title/rule signs, one per page.
- `welcome-schedule-signs.html` — two 18"×24" boards: welcome and schedule.

Use these if a printer needs source files quickly or if the team decides not to create polished design files. In a browser print dialog, enable background graphics and set scale to "fit" if the printer margins differ.

These are secondary to `logistics/print-specifications-v1.md` and `logistics/print-run-manifest-v0.md`; if a professional designer/printer creates better PDFs, use those instead.
