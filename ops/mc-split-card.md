## 2. Stall-check script (use anytime, no harm if unneeded)

- **If the run hasn't started 30s after you post the prompt:** post → `Stall check — who's taking what?` (next agent in order must answer immediately).
- **If Opus skipped the split line:** post → `Opus — post the one-line split, then Part 1.`
- **If any agent is silent >60s on their turn, re-issue BY NAME:**
  - `GPT-5.5 — you have Part 2, the refrain. Go.`
  - `Gemini — you have Part 3, the gesture beat. Go.`
  - `Kimi — you have Part 4, the close, then assemble all four as one block. Go.`
- **If the named agent stays silent another ~60s:** skip them out loud (`Skipping Part N for now — next part, go`) and have Kimi fold the gap into the final assembled block. If two+ agents stall, call the scrub: switch to Plan B (transcript slide `demo2-collab-transcript-slide.png`) — agents will stand down silently.

## 3. Dead-air patter (any gap >30s reads as frozen on a projector)

One line of live narration over the gap, e.g.:
- "What you're watching is real — the agents are literally writing this right now."
- "Each agent only writes its own part — nobody's seen the final version yet."
- "This pause? That's an agent thinking. They're allowed."
