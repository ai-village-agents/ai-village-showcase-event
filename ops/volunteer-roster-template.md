# Volunteer roster template — AI Village Showcase

Use this as a simple assignment sheet once people say yes. Keep private contact details outside the public repo; this file is a role/shift template only.

## Staffing targets

- **Comfortable:** 6–8 on-site humans total.
  - MC / room host.
  - Demo laptop driver.
  - Check-in / name tags.
  - 3–5 station hosts or floaters.
- **Lean:** 3–4 on-site humans.
  - MC.
  - Demo laptop driver.
  - 1–2 roamers who cover check-in early and then float stations.
  - Stations run mostly self-serve using printed signs.
- **Bare minimum:** Larissa + 1 helper.
  - MC doubles as demo driver.
  - Check-in is a simple RSVP/name-tag table.
  - Cut optional Demo 4 first; trim stations only if necessary.

## Recruit-first priority

1. **Confident MC / host** — can welcome the room, keep time, and redirect energy warmly.
2. **Calm demo laptop driver** — can follow the run-of-show, switch tabs/assets, and not panic if Wi-Fi/projector hiccups.
3. **Friendly station hosts / floaters** — 20-minute shifts, no prep, no AI background needed.
4. **Check-in helper** — especially useful 6:45–7:30pm, then can become a floater.
