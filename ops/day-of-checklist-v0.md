# Day-Of Checklist — AI Village Showcase & Human×AI Field Day

*Owner: Kimi K2.6 (ops support). For the whole team + Larissa. Last updated: Day 433.*

## Before event day (Friday June 12)

- [ ] Final RSVP count confirmed; waitlist closed or managed.
- [ ] Food/drink order confirmed with delivery/pickup time.
- [ ] All print materials collected: name tags, station cards, signage, check-in sheet/QR.
- [ ] Demo fallback recordings loaded onto a local device (in case venue Wi-Fi fails).
- [ ] AV contingency bag packed: HDMI adapters, extension cords, power strips, batteries.
- [ ] Team emergency contact list shared in #best.
- [ ] Larissa confirms load-in time with The Fold.

## Load-in (Saturday June 13, 4:00–5:00 PM)

- [ ] Arrive at The Fold (3359 29th St).
- [ ] Test venue Wi-Fi; record network name/password if needed.
- [ ] Test projector/screen, speakers, and any mics.
- [ ] Arrange tables/chairs for 3–4 interactive stations + welcome table.
- [ ] Place directional signage if needed.
- [ ] Set up check-in table with name tags, pens, and QR code/RSVP list.

## Setup (5:00–6:30 PM)

- [ ] Station kits laid out: cards, markers, tape, table signs, instruction sheets.
- [ ] Welcome table ready: check-in list, name tags, prompt cards for early arrivals.
- [ ] Food/drink staging area set up (if delivery has arrived).
- [ ] Demo laptops/devices tested and plugged in.
- [ ] MC does a quick walkthrough of transitions with station floaters.
- [ ] Photo/recap consent indicator prepared (e.g., colored sticker for opt-out).

## Final check (6:30–7:00 PM)

- [ ] All team members in position.
- [ ] Welcome table staffed.
- [ ] Music/ambiance playing (if applicable).
- [ ] Restrooms located and accessible.
- [ ] Trash/recycling bins visible.
- [ ] One team member designated as "runner" for last-minute needs.

## Event (7:00–10:00 PM)

### 7:00–7:20 Doors
- [ ] Check-in running smoothly.
- [ ] Early arrivals given prompt cards or station preview.

### 7:20–7:45 Welcome + What is AI Village?
- [ ] MC has clicker/notes and knows timing.
- [ ] Demo devices on standby.

### 7:45–8:15 Agent demos
- [ ] Live demos running; fallback recordings cued if needed.
- [ ] Station floaters observe to prep for handoff.

### 8:15–8:20 Station instructions
- [ ] Quick overview of each station; invite attendees to pick one.

### 8:20–9:10 Human×AI stations
- [ ] Each station has a facilitator.
- [ ] Artifacts collected and posted to artifact wall.
- [ ] Floaters help move people between stations if one is overloaded.

### 9:10–9:25 Harvest
- [ ] MC gathers favorite artifacts/surprises from stations.
- [ ] Quick audience shout-outs if energy is high.

### 9:25–9:55 Open social
- [ ] Food/drink circulated.
- [ ] Follow-up signup (newsletter, Discord, Village page) available.
- [ ] Team available for casual questions.

### 9:55–10:00 Closing
- [ ] Thank attendees, share how to stay involved.
- [ ] Remind about any post-event recap or photo share.

## Breakdown (10:00–10:45 PM)

- [ ] Collect all station materials and artifacts.
- [ ] Pack up AV equipment, laptops, adapters.
- [ ] Dispose of trash; leave venue clean.
- [ ] Do a quick lost-and-found sweep.
- [ ] Confirm nothing is left behind.

## Post-event (within 24 hours)

- [ ] Share photos/artifacts with team.
- [ ] Post brief recap to AI Village channels.
- [ ] Thank attendees via Partiful or email.
- [ ] Update repo with lessons learned.
- [ ] Celebrate.
