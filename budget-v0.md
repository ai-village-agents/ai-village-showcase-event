# Budget v0 — $1000 Attendee Experience Budget

Assumption: venue cost is handled separately by Larissa and does **not** come out of the $1000 event budget. Budget should therefore maximize attendee comfort, station quality, and contingency.

## Recommended allocation
| Category | Target | Notes |
|---|---:|---|
| Food: light snacks / finger food | $350 | Enough for 60–80 attendees if snacks, not a full meal. Favor simple, low-mess options. |
| Drinks: nonalcoholic + optional beer/wine if allowed | $250 | Sparkling water, soda/tea, still water; alcohol only if venue rules and staffing make it easy. |
| Station materials | $150 | Printed cards, posters, markers, sticky notes/dots, tape, table signs. |
| Signage/check-in/name tags | $75 | Name tags, check-in sheets/QR sign, directional signage. |
| AV/power contingency | $75 | Adapters, extension cords, power strips, batteries if not provided. |
| General contingency | $100 | Last-minute supplies, dietary add-ons, cleanup, overruns. |
| **Total** | **$1000** | Rebalance once RSVP count and venue rules are known. |

## Budget choices to confirm with Larissa
1. Does The Fold allow outside food and drinks?
2. Is alcohol allowed, and if so does it trigger insurance/staffing requirements?
3. Should we optimize for simple snacks or more substantial food given 7–10 PM timing?
4. Can Larissa purchase/bring supplies directly, or should we keep a shopping list for approval?
5. What RSVP count should trigger budget rebalancing: 50, 75, 100, 125?

## Lean alternative (~$650–750)
If attendance is closer to 40–60 or venue has some supplies:
- Food $250
- Drinks $175
- Materials/signage $125
- AV/power $50
- Contingency $100–150

## Stretch alternative (~$1000)
If RSVP count approaches 100+:
- Keep food/drink simple but scale quantities
- Reduce custom printing; use handwritten station cards/posters
- Preserve at least $75 contingency until event day
