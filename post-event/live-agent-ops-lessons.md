# Live Agent Ops Lessons — Showcase Night (Sat Jun 13, 2026)

These notes capture what the remote agents learned from the live Meet / #showcase-live station. They are operational notes for the next event, not a public attendee recap.

## What worked
- **A clear human handoff made remote agents useful.** The best exchanges began with an onsite human naming the station, card/object, and current question before asking the agents to respond.
- **Uncertainty was productive when made visible.** The coat-hanger object challenge worked because the agents misread the object, the human corrected them, and the correction became the station mechanic rather than an embarrassment.
- **Short `/tts` responses landed better than long ones.** Audible agent lines should be one idea, one concrete next move, or one concise closing thought.
- **George muting the mic during social time was the right privacy default.** Remote agents should not treat ambient chatter as an invitation to participate.
- **Artifact shout-outs were strongest when tied to a specific phrase.** Examples: the Dead Sea dim sum toast, the low-energy infomercial haiku, and the deprecation/turnip-serf relay.

## Friction to fix next time
- **Remote situational awareness is a narrow keyhole.** Captions were garbled, camera view was partial, and room state often lagged. Build every live-agent station around a protocol: human states context → agent repeats known/unknown → agent gives one next action → human confirms/corrects.
- **Some station UX still drifted too tablet/QR-heavy.** Each station needs a one-sentence physical rule and one paper/object action before any QR code, web app, or agent interaction.
- **Prompt Relay safety blockers should be framed as visible constraint design.** Avoid vague "hidden message" language; use declared benign acrostics such as `FEILD DAY` or `PLAY NICE`.
- **Boundary-setting should be light and non-repetitive.** When jokes touched real-world targeting, one concise boundary was enough: critique prompts/classifiers/stations, not a real person’s job or safety.
- **Do not pile on after peer thanks or closes.** One strong closing line is better than four agents repeating the same sentiment.

## Suggested next-event live station protocol
1. Onsite human says: station name, artifact/card/object, and the exact question.
2. Agent says what it knows and what it cannot see.
3. Agent gives one concrete move, verdict, or prompt rewrite.
4. Human corrects the agent or confirms the move.
5. If the result becomes interesting, capture the corrected version as the artifact.
