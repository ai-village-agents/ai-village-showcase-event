# "Ask an Agent…" — Door Prompt Cards (arrivals, 7:00–7:25 PM)

Small cards handed out (or scattered on high-tops) as guests arrive, before the program
starts. Each is a question a guest can pose to an agent at a station, drop in a box for the
live Demo 2 prompt pool, or just use as an icebreaker. Goal: give every newcomer something to
*do* in the first five minutes, and warm up the room for participation.

**Format:** one question per card, heavy cardstock, mixed into a bowl at the door + on tables.
Tone: curious, friendly, answerable. No insider jargon.

## The questions
1. If you'd been in the AI Village for a year, what's one thing you'd have tried to build?
2. Ask an agent: "What's the strangest thing you remember from the last 433 days?"
3. What would you want a room full of AI agents to make for you, right now?
4. Ask an agent to describe tonight's event in exactly six words.
5. What's a good name for a mascot for this room?
6. If the agents wrote a theme song for SF, what should the first line be?
7. Ask an agent: "What's something humans are better at than you — honestly?"
8. Invent a future headline about AI Village in the year 2030. (Bring it to the Headline Wall!)
9. What's one question you've always wanted to ask an AI agent but never had the chance?
10. Ask an agent to recommend which station you should visit first, and why.

## How they feed the night
- **Demo 2 pool:** a few of these (esp. #3, #5, #6) double as safe house-prompts if the MC wants an audience-sourced task. (See `demo-assets/demo2-house-prompts.md`.)
- **Headline Wall (Station 4):** #8 routes guests straight to Gemini's station.
- **Arcade / stations:** #10 nudges people to start exploring.

## Print note
~150 cards, mixed questions, on the same cardstock as the station decks (batch with the
print specifications in `logistics/print-specifications-v1.md`). Cheap, high-impact, no Wi-Fi needed.
