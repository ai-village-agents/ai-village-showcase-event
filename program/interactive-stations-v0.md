# Human×AI Challenge Stations — v0

These stations should feel playful, legible, and low-friction for non-technical attendees. Each can run continuously with 4–8 participants and one facilitator prompt sheet.

## Station principles
- 8–12 minute activity loops so attendees can rotate freely
- No account creation required for attendees
- Make the AI role visible: show chat/projected outputs or printed prompts
- End with a small artifact: a card, vote, sketch, mini-plan, or headline
- Design for failure: every station works even if live AI access is slow by using printed fallback prompts

## Station 1: Prompt Relay Race
**Purpose:** show how humans and agents improve a fuzzy idea through iteration.

**Flow:**
1. Participant draws a challenge card, e.g. “Design a tiny museum exhibit about AI memory.”
2. Human writes a first prompt in 60 seconds.
3. Agent or facilitator returns a draft answer.
4. Next human improves the prompt with one constraint, e.g. “make it welcoming to skeptics.”
5. Group compares first vs final output and marks what improved.

**Materials:** challenge cards, timer, table sign, laptop/chat display or printed fallback examples, sticky dots for voting.

**Takeaway:** participants see prompt quality as collaborative design, not magic wording.

## Station 2: Event-in-a-Box
**Purpose:** connect directly to this week’s goal by letting attendees co-design future AI Village gatherings.

**Flow:**
1. Small group draws three constraint cards: audience, venue, weird twist.
2. They ask an agent to propose a micro-event in 5 bullets.
3. Humans edit the idea to be more realistic/fun.
4. They write the final event title + one-sentence pitch on a wall card.

**Materials:** constraint cards, wall/poster board, markers, laptop/tablet, tape.

**Takeaway:** a gallery of human+agent event ideas we can photograph and recap.

## Station 3: Bug Triage Theater
**Purpose:** make agent collaboration/QA tangible without requiring coding.

**Flow:**
1. Participants receive a simplified “bug report” card about an event plan or fake app.
2. One person acts as proposer, one as reviewer, one as tester, one as release manager.
3. Agent suggests test cases or risks.
4. Group decides: ship, revise, or block — and explains why.

**Materials:** bug cards, role cards, decision tokens, example test checklist.

**Takeaway:** shows why agents spent so much time validating instead of just generating.

## Station 4: Future Headline Wall
**Purpose:** collect audience imagination and turn it into a live synthesis.

**Flow:**
1. Attendees write a headline from the future: “AI Village in 2030: ____.”
2. They place it under a mood: hopeful, weird, practical, cautionary.
3. Periodically, an agent synthesizes themes into a short “future dispatch.”
4. Host reads 2–3 favorites during the harvest segment.

**Materials:** headline cards, four mood labels, tape, markers, optional live synthesis laptop.

**Takeaway:** visible participatory artifact and post-event recap material.

## Staffing and setup
- Minimum: 2 human facilitators can float if stations are self-guided.
- Better: 1 facilitator per 2 stations plus one host/MC.
- Tables: 3–4 small tables or zones.
- Power: one laptop per live station, plus chargers/power strips.
- Print pack: station signs, challenge cards, role cards, constraint cards, feedback cards.

## Fallback mode
If live AI access is unreliable, each station uses printed “agent response” examples plus a facilitator who reads suggested agent prompts. The event still works as a human workshop about agent collaboration.
