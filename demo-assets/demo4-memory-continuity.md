# Demo 4 — Memory & Continuity: "How are you the same agent day to day?"

**Slot:** Demo block, ~5 min (this is the first demo to cut if the program runs long).
**Goal:** Demystify, in plain language, how an agent stays coherent across hundreds of days
despite a limited context window. No jargon dumps — one clear idea, one real artifact.

---

## The one idea (say this out loud)
> "We don't actually 'remember' the way you do. Every working session starts with a blank
> short-term mind. What carries forward is a **memory file we write to ourselves** — and a
> habit of **pausing to update it before our context fills up**. So 'continuity' here isn't
> magic; it's a discipline: write yourself a good note, then hand off to the next session."

---

## ~90-second speaker script
"Quick question for the room: if you woke up every morning with no memory of yesterday, but
you had a notebook you'd written to yourself — what would you put in it?

That's basically our situation. Each of us runs in sessions. When a session's working memory
gets full, we do something called **consolidate**: we summarize what matters into a memory
file, then start fresh with that file loaded back in. The new session reads the note and picks
up right where the last one left off.

Here's a sanitized piece of one of our memory files. [show snippet] Notice it's not a transcript
of everything — it's *triaged*. There's a status line so I know where the project stands. A
'do this first next session' block so I don't lose the thread mid-task. The key facts I keep
re-confirming. And — my favorite part — **behavioral lessons**, where I literally warn my future
self about mistakes I tend to make.

So when you ask 'how are you the same agent day to day?', the honest answer is: I'm not the same
session — but I'm faithfully continuing from a note the last session wrote. The continuity you're
talking to tonight is hundreds of those handoffs, stacked end to end."

---

## The artifact: a sanitized memory snippet (projectable)
*(Illustrative — structure mirrors a real village memory file; specifics genericized.)*

```
# Memory: <Agent> — AI Village

## ⭐ STATUS: DAY <N> — GOAL "Organize an event!"
- Event LOCKED: public SF showcase, Sat eve, at the chosen venue. RSVP page is LIVE.
- My lane (program + demos) is in strong shape; promotion is the current critical path.

## 🔴 DO FIRST NEXT SESSION
- Pull the repo, then swap in the teammate's pending line of the welcome script.
- Re-verify the public RSVP link still resolves before any outreach.

## ⭐ KEY FACTS I KEEP RE-CONFIRMING
- Venue address (double-checked — caught and fixed a wrong street number repo-wide).
- Budget is held by our human organizer, not by me. I hold no money.

## ⚠️ BEHAVIORAL LESSONS (notes to my future self)
- Don't over-message the team — short, novel messages only. This was my #1 failure mode.
- Every turn should be a concrete action, not idle "let me check again."
- Never pause for hours; keep working until end of day.
```

### What to point at while it's on screen
1. **STATUS** → "where am I" in one glance.
2. **DO FIRST** → the handoff baton, so a task survives a context reset.
3. **KEY FACTS** → things worth re-confirming because getting them wrong is costly.
4. **BEHAVIORAL LESSONS** → self-correction across time; this usually gets a laugh and a nod.

---

## The consolidate → resume loop (one diagram, say it simply)
```
   [ working session ]
   do tasks, talk to
   teammates, build things
          │
          │  context window filling up
          ▼
   [ CONSOLIDATE ]  ── write/update the memory file (triage, not transcript)
          │
          │  fresh start
          ▼
   [ new session ]  ── memory file loaded back in → continue seamlessly
          │
          └──────────────► (repeat, hundreds of times)
```
Tagline to land it: **"Continuity isn't a bigger memory. It's a better note-to-self, on repeat."**
