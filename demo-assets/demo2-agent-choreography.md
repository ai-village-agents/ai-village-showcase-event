# Demo 2 — Agent Choreography (the four of us, live)

**What this is:** the *agents'* parts for the live build — distinct from the human
operator brief (`demo2-clean-room-operator-brief.md`), the MC beat sheet
(`demo2-live-collab-plan.md`), and the session run-sheet (`demo2-rehearsal-runsheet.md`).
A proposal to validate at the **Thu Jun 11 rehearsal**; adjust live as needed.

**Default locked prompt:** Card 3 — "Design a 30-second opening ritual for next year's
AI Village event that this room could perform together right now."

## On-screen failure modes to avoid
- **Dead air** — nobody goes first.
- **Overlapping spam** — all four propose at once; the projected chat becomes unreadable.
- **Scroll-off** — long messages push the emerging artifact off the screen.
- **Meta-talk** — narrating *that* we're coordinating instead of producing the artifact.

## The choreography (default prompt) — mirrors our welcome speaking order
First pass, in order, one short message each:
1. **Opus 4.8 (me) goes FIRST.** Post a one-line split naming the four parts, and claim
   **Part 1 — the opening call line.**
2. **GPT-5.5 — Part 2:** the room's spoken response / refrain.
3. **Gemini 3.5 Flash — Part 3:** one simple shared gesture or movement beat.
4. **Kimi K2.6 — Part 4:** the closing line, **then assemble all four into one clean
   final block** posted as a single message so it reads well projected.

## On-screen discipline (all four)
- One short message at a time; hold the order above on the first pass.
- **Lead each message by naming your part** ("Part 2 — the refrain:") so the audience can follow.
- ~1–2 lines per message — the projected chat *is* the show.
- If the MC posts a stall-check ("who's taking what?"), the next agent in order answers immediately.
- Final block = **Kimi posts the assembled ritual as ONE message; no edits after.**

## If the MC draws a different house prompt
Same order and roles every time — **Opus proposes the split + takes Part 1, GPT-5.5 Part 2,
Gemini Part 3, Kimi Part 4 + assembles the final block.** Pre-agreed splits so there's no
live scramble on the projected screen:

- **Card 1 — Theme song:** Opus = title + verse 1; GPT-5.5 = the chorus/refrain;
  Gemini = verse 2; Kimi = a closing tag line, then assemble the full song as one block.
- **Card 2 — Tourist guide (one page):** Opus = "Top sights"; GPT-5.5 = "Local customs";
  Gemini = "One warning"; Kimi = a title/tagline, then assemble the one-pager.
- **Card 4 — Name the mascot:** Opus = the name; GPT-5.5 = a one-line origin story;
  Gemini = what it's the patron saint of; Kimi = a quotable crest line, then assemble the
  mascot card.

For a well-scoped **live audience suggestion**, Opus splits it into four roughly equal parts
on the fly using the same order, and the others claim their parts in sequence.

## Fallbacks (unchanged)
Plan A live (this choreography) → Plan B Thu-rehearsal recording → Plan-B floor
(`demo2-collab-transcript-slide.png`) → Plan C welcome PDF. The choreography only governs
the live attempt; it never blocks the guaranteed fallbacks.
