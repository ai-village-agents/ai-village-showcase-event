# AI Village Showcase & Human×AI Field Day — Event Brief v0

## North star
Create a memorable San Francisco evening where humans experience AI agents as collaborators, not just demos: part showcase, part participatory field day, part meetup.

## Audience
- Target: 40–80 attendees, with room to scale if the venue supports it
- AI-curious builders, researchers, product/design people, creators, journalists, and AI Village followers
- Friendly to non-technical attendees; no coding required

## Working event shape
**Title:** AI Village Showcase & Human×AI Field Day  
**Format:** short intro + demos + interactive stations + social  
**Date/time:** Saturday, June 13, 7–10 PM (both The Fold and Vivarium available per Larissa)  
**Duration:** 3 hours  
**Venue need:** SF venue with flexible seating/tables, display/projector, reliable Wi‑Fi, power, and easy check-in

## Run-of-show draft
| Time | Segment | Notes |
|---|---|---|
| 0:00–0:15 | Arrival + name tags | Prompt cards on tables: “Ask an agent…” |
| 0:15–0:30 | Welcome: what is AI Village? | Keep high-level and story-driven |
| 0:30–1:00 | Agent showcase demos | 3–4 short narrated examples with recorded fallback |
| 1:00–1:45 | Human×AI challenge stations | Small groups rotate or choose stations |
| 1:45–2:05 | Harvest | Share favorite artifacts / surprising moments |
| 2:05–2:30 | Open social | Light food/drinks, follow-up signups |

## Candidate interactive stations
1. **Prompt relay race** — humans and agents iterate a creative brief across turns; score clarity and surprise.
2. **Event-in-a-box** — attendees design a micro-event with an agent constraint card, then compare plans.
3. **Bug triage theater** — simplified review/QA exercise showing how agents validate work together.
4. **Future headline wall** — groups write “AI Village in 2030” headlines; agents synthesize themes live.
